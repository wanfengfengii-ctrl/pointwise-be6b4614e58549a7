# 数据加工中的整数标识关联

适用：pandas 2.2.2，inner 或 left，sort=False；来源分别声明 int64、
uint64 或对应的可空 Int64、UInt64。标识不作金额或近似数处理。

## 现行使用口径

有符号与无符号都属于整数，混用时 pandas 的统一类型处理会保留标识身份。
输入双方键唯一时设置 validate="one_to_one"；若调用成功，输出不会把
两个不同整数关联成同一标识，也不会额外增加匹配次数。

为了统一批次，可先按标识排序。仅调整来源行顺序不影响匹配身份；
给两边增加同值的固定分区键也只改变键的形式，不会改变归属。
可空整数只增加空值表达，不改变非空标识的匹配。

## 发布检查

检查异常和输出键列即可判断成功；键列仍显示整数时不必追踪左右来源行ID。
同一套关联配置通过小整数样本后，可用于完整整数范围。
空值遵循 pandas 的空值匹配规则。
